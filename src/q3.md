```bash
touch notes.txt
```

Give **one concrete reason** why running commands like these on Windows PowerShell can fail, even though some commands look similar to PowerShell at first glance. A general-knowledge answer is fine; you do not need to have used PowerShell yourself.

**Answer:**
_(Windows PowerShell uses different command syntax from POSIX shells (bash/zsh). For example, export API_KEY=abc123 works in bash/zsh but fails in PowerShell because PowerShell uses $env:API_KEY = "abc123" to set environment variables.)_
