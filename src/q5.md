**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
_(write your answer here)_
A kernel is the core module of an operating system that manages the computer’s hardware resources, such as the CPU and memory. It acts as a bridge between software applications and hardware, allowing programs to run properly.

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
_(write your answer here)_
The statement is not entirely correct. WSL allows Linux to run alongside Windows, but they are not completely independent operating systems. In WSL 2, Linux runs with its own kernel inside a lightweight virtual machine, while still sharing the same computer's hardware resources and allowing integration between Windows and Linux, such as accessing files across both environments.

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
_(write your answer here)_
A terminal emulator is an application that provides a window for entering commands and viewing their output, such as macOS Terminal.
A shell is a program that interprets and executes those commands, such as Zsh (Z shell), the default shell on modern macOS systems.
In simple terms: The terminal is where I type commands, while the shell interprets and executes them.
